# 배분 규칙 보강

## 1. 언제 쓰는지
- `web/engine.js`의 과 추천 결과를 시험 문항과 접수대장 정답에 대조해 배분 규칙을 개선할 때 사용한다.
- 입력은 `data/배분기준표_소관키워드_304건.csv`, `data/A부_조직도_26개과.csv`, `data/시험_요구문항_40건.csv`, `data/요구자료_접수대장_2026국감_520건.csv`와 사용자가 선택한 수정 방법이다.

## 2. 순서
1. `PROGRESS.md`와 `CONTEXT.md`를 읽고 원본 CSV와 `web/engine.js`를 확인한다. 시험 40건과 접수대장 520건의 변경 전 1순위 정답 수를 계산한다.
2. 틀린 시험 문항을 원인별로 묶는다. 각 문항의 정답 과와 1순위 과, 점수, 근거키워드, 해당 규칙의 제외어와 우선순위를 확인한다. 같은 키워드가 여러 과에 걸리거나 범용 키워드가 구체 키워드보다 앞서는 경우를 구분한다.
3. 원인마다 수정 방법 하나를 구체적인 규칙 ID와 변경 값으로 제안한다. 방법은 제외어 추가, 키워드 추가, 우선순위 조정 중에서 고른다. 새 규칙의 과는 조직도 26개 과 안에 있어야 한다. 사용자가 고른 방법만 적용한다.
4. 원본 기준표를 복사한 `data/rules_보강.csv`에서 선택된 행만 수정한다. 변경 전·후를 같은 엔진으로 재채점해 시험 40건과 접수대장 520건의 1순위 정답 수, 새로 틀린 문항 수와 번호를 표로 비교한다. 차이가 예상과 다르면 원인을 확인하고 다시 계산한다.
5. 변경한 규칙 ID·값, 비교 결과, 남은 오답과 막힌 점을 `PROGRESS.md`에 기록한다. 시험 1순위가 30/40 이상이고 새로 틀린 문항이 0건일 때만 이 절차를 스킬로 보존한다.

## 3. 끝나는 조건
- `data/rules_보강.csv`의 변경 행이 사용자 선택과 정확히 일치하고, 원본 기준표는 그대로다.
- 시험 40건과 접수대장 520건의 변경 전·후 1순위 정답 수 및 새 오답 수가 실제 실행 결과로 확인된다.
- 스킬 저장 조건은 시험 1순위 30/40 이상 및 새 오답 0건이다. 조건에 미달하면 스킬을 저장하지 않고 결과와 남은 문제를 보고한다.

## 4. 하지 말 것
- 사용자가 고르지 않은 제외어·키워드·우선순위 변경을 사본에 반영하지 않는다.
- 원본 배분기준표나 접수대장의 정답 값을 고치지 않는다. 규칙을 엔진 코드에 직접 넣지 않는다.
- 시험 정확도를 실제 국회 업무의 정확도로 주장하거나 AI 추천을 최종 배분으로 확정하지 않는다.
